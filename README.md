# OrthoPass

Orthopaedics flashcards and clinical-vignette MCQs for MBBS exam revision. Works on Android, iPhone and laptop, and works offline once installed.

- Decks: Spinal Disorders, Paediatric Orthopaedics, Diabetic Foot & Soft Tissue Infections, Chronic Joint Disease, Musculoskeletal Tumours, Compartment Syndrome
- 520 flashcards and 255 MCQs
- To add a new deck, open the Decks tab and tap "Import deck file". The JSON format is shown under "Show the AI prompt".

Progress is saved in your browser on each device. To move it to another device, use Decks → Save progress / Restore progress.
